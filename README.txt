RAMZIE ROSLI GALLERY: what is in this folder
=============================================
index.html   the gallery (do not edit)
admin.html   the Map Manager: drop in maps, place them, download an update
maps.json    the list of rooms, maps, prices and reviews
images/      the map pictures

HOW TO PUT THE SITE ONLINE (first time)
1. Make a new Public repository on GitHub.
2. Drag ALL of these files and the images folder into it (Add file > Upload files) and commit.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.

HOW TO ADD OR CHANGE MAPS LATER
1. Open  https://YOUR-SITE/admin.html  (it loads your current maps.json by itself).
2. Drop in the new map images, fill in title and subtitle, choose the room, press "Place map".
3. Press "Download update (zip)" and unzip it.
4. In your GitHub repository: Add file > Upload files. Drag in the unzipped maps.json and images folder.
   Say yes to replacing maps.json. Commit. The site updates in about a minute.

Your Etsy shop link, prices and guestbook reviews are edited in the same Map Manager page.
